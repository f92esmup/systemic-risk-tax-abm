## Ejecución del Sistema
Existen dos formas principales de ejecutar la simulación y generar los resultados:

### Opción 1: Scripts de Python
Puedes ejecutar la simulación y la generación de figuras por separado mediante la terminal:

1. **Ejecutar la simulación principal:**
   ```bash
   python main.py
   ```

2. **Generar las figuras:**
   ```bash
   python figuras.py
   ```

### Opción 2: Jupyter Notebook
Alternativamente, puedes utilizar el notebook principal para ejecutar todo el flujo de trabajo (simulación y análisis) en un solo lugar:

- **Archivo**: `MAIN.ipynb`
